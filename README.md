# Financial LLM Copilot

AI-powered macroeconomic analysis covering **102 countries** across **14 sub-regions**
with **12 indicators**.

## Features

- Chat with a QLoRA fine-tuned Mistral-7B model for financial analysis
- Regional economic analysis with interactive charts
- Global country rankings by any indicator
- Side-by-side country comparisons
- Data triangulated from FRED, World Bank, and OECD

## Tech Stack

- **Frontend**: Streamlit
- **LLM**: QLoRA fine-tuned Mistral-7B-Instruct-v0.3 (LoRA `r=16`, `alpha=32`, all 7
  attention/MLP projections, 41.9M trainable params = 0.58% of base), merged and
  served as a Q4_K_M GGUF
- **Inference**: llama-cpp-python
- **Data Sources**: FRED, World Bank, OECD APIs
- **Visualization**: Plotly
